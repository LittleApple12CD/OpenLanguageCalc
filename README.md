# OpenLanguageCalc
- A calculator program implemented in 17 programming languages, intended for comparison and learning.<br>
- 一个由17种编程语言实现的计算器程序，用于比较和学习。

# Details 详情
- 本项目由 C, C++, C#, Zig, Rust, Kotlin, Java, JavaScript, TypeScript, Go, Python, Lua, Batch, VBScript, PowerShell, FASM, NASM 分别实现，用于比较不同语言（或汇编器）之间的区别。
- This project is implemented in C, C++, C#, Zig, Rust, Kotlin, Java, JavaScript, TypeScript, Go, Python, Lua, Batch, VBScript, PowerShell, FASM, and NASM respectively, for comparing the differences between different languages (or assemblers).

# How to run 如何运行
- 安装必要的环境后，从 [GitHub Releases](https://github.com/LittleApple12CD/OpenLanguageCalc/releases) 下载发布包，解压后运行里面的 EXE / BAT 或 PS1 文件
- After installing the necessary environments, download the release package from [GitHub Releases](https://github.com/LittleApple12CD/OpenLanguageCalc/releases), extract it, and run the EXE / BAT or PS1 file inside.

# Prerequisites 必要环境
- Java: Java 21
- C#: .NET Runtime 10.0
- JavaScript: Node
- Lua: Lua 5.5 Binary
- Python: Python 3.12
